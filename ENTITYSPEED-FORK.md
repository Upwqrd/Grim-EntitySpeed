# GrimAC: EntitySpeed 40 км/ч для 2b2t.org.ru

Целевая платформа — Folia 1.21.11. Версия форка: `2.3.74-2b2t-entityspeed40`.
Это локальный форк исходников; исходная папка получена без каталога `.git`.

## Поведение

- Допустимое дополнительное горизонтальное движение: **40 км/ч = 11,111111 блоков/с = 0,555555556 блока/тик** при 20 TPS.
- Для Meteor укажите скорость **11.111111** блоков/с. В старой версии модуль называется EntitySpeed; в новой — EntityControl → Speed. Fly должен быть выключен. Во время обязательной серверной отдачи ускорение не предоставляется.
- Поддерживаются лодки, осёдланные лошади/ослы/мулы, скелетные и зомби-лошади, верблюды, свиньи и страйдеры. Для свиньи/страйдера требуется соответствующая удочка в одной из рук.
- Разрешение получает только первый пассажир транспорта, который сам не едет на другом транспорте. Ламы, вагонетки, наутилусы и счастливые гасты исключены.
- Лимит круговой по XZ: диагональ не увеличивает скорость. Замедление паутиной/кустами учитывается. Разрешение распространяется также на горизонтальное движение во время обычного падения/прыжка, сохраняя вертикальную физику.
- Существующие варианты ванильной физики сохранены: это предел дополнительного EntitySpeed, а не принудительное ограничение законной скорости лодки на льду или серверного импульса.
- Общие Simulation, Phase, VehicleTimer, порядок пакетов, транзакции и setbacks не отключаются. Допуск Y не увеличивается.

## Реализация и проверка безопасности

`EntitySpeedAllowance` добавляет альтернативы к обычным векторам предсказания.
В `PredictionEngine.doPredictions` ограниченное движение XZ применяется **после** стандартного расчёта неопределённости, **перед** обычной проверкой коллизий. Поэтому допуски X/Z не расширяют круг до квадрата, а стены и земля продолжают обрезать движение. Y берётся из стандартной физики, а не из пакета игрока.

Проверены следующие границы:

| Сценарий | Защита / проверка |
|---|---|
| Ускорение по диагонали | Норма `hypot(X, Z)` ограничивается общим пределом; 10 000 случайных направлений |
| Превышение 40 км/ч | Дополнительный кандидат остаётся на границе лимита; остаток остаётся ошибкой Simulation |
| BoatFly: набор высоты, зависание, anti-kick -0,0313 | Проверка на 200 тиках реальной функции `floatBoat`: запрос клиента не заменяет предсказанную гравитацию |
| Phase через стену / землю | Кандидат проходит реальный `Collisions.collideBoundingBoxLegacy` |
| AntiKB / Explosion | При любом ожидаемом импульсе дополнительные кандидаты отсутствуют; векторы импульсов не переписываются |
| NaN / Infinity / огромные координаты | Проверка конечности; отсутствует неограниченное расширение кандидата |
| Выход из транспорта | Без серверно отслеживаемого транспорта разрешение отсутствует |
| EntityControl без седла / без удочки | Проверяется серверное седло и предмет управления |
| Второй пассажир / вложенный транспорт | Дополнительные кандидаты не создаются |
| Полёт на гасте / неизвестный транспорт | Закрытый список поддерживаемых типов |
| Timer / packet spam / транзакционные дизейблеры | Их обработчики не изменены, разрешение считается на тик движения, не на секунду клиента |

Для современной системы седла у свиней/страйдеров включено отслеживание серверных equipment-пакетов. Ускорение хранится в локальных кандидатах предсказания; новых общих изменяемых состояний и вызовов Bukkit из потоков проверки нет.

Источники для анализа Meteor (код не копировался):

Существующие upstream-допуски при посадке, лаге, коллизиях с сущностями и переходах воды не переписывались. Проверка запуска сервера не заменяет игровые испытания Meteor, задержек и переходов между регионами Folia.

## Сборка

Gradle запускается на JDK 25 из-за требований текущего buildSrc/Fabric Loom; компиляция common использует toolchain JDK 21. Для Bukkit можно исключить конфигурирование Fabric:

```powershell
$env:JAVA_HOME = Split-Path (Split-Path (Get-Command java).Source) # если java в PATH — JDK 25
.\gradlew.bat :common:test :bukkit:verifyBundledServiceProviders -PbukkitOnly=true -PshadePE=true -Prelease=true --no-configuration-cache --console=plain
```

Артефакт: `bukkit/build/libs/grimac-bukkit-2.3.74-2b2t-entityspeed40.jar`.
PacketEvents включён в этот JAR; отдельный PacketEvents для этой сборки не требуется.
Отчёт тестов: `common/build/reports/tests/test/index.html`.

Полный прогон: **63 теста, 0 ошибок, 0 пропусков**, в том числе 15 тестов EntitySpeed. Сборка дополнительно проверяет наличие классов, перечисленных в ServiceLoader-дескрипторах. Для самодостаточного JAR отключена минимизация зависимостей: в исходной сборке она удаляла Adventure-провайдер и мешала загрузке плагина на Folia.

Проверка собранного архива нашла 4 корректных записи встроенных провайдеров. После исправления упаковки выполнен повторный запуск Folia: GrimAC включён (зелёный в `plugins`), обработчики пакетов и tick schedulers зарегистрированы, сервер дошёл до `Done`, ошибок/исключений в журнале этого запуска нет. Minecraft status handshake вернул `Folia 1.21.11`, protocol `774`; ответ сохранён в `.local-folia/status.json`. Игроки с Meteor в этих испытаниях не подключались.

## Локальный сервер

Подготовлен официальный Folia **1.21.11 build 14**, SHA256:
`f52c408490a0225611e67907a3ca19f7e6da2c6bc899e715d5f46844e7103c39`.
Файл скачан через `https://fill.papermc.io/v3/projects/folia/versions/1.21.11/builds/14`, контрольная сумма проверена.

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Start-LocalFolia.ps1
```

Скрипт копирует собранный плагин и запускает сервер из `.local-folia`. Первичная конфигурация: **127.0.0.1:25565**, online-mode=true, allow-flight=false, RCON выключен. Сервер не публикуется в интернете. Остановка — `stop` в консоли сервера. Лог: `.local-folia/logs/latest.log`.

Перед переносом на основной сервер выполните игровую проверку с непривилегированным аккаунтом без `grim.exempt`/`grim.disabled`/`grim.nosetback`: вода, берег, суша, паутина, препятствия, прыжок, падение, седло/удочка, смена пассажиров и регионов; скорости 36/40/45 км/ч; отдельно Fly и anti-kick. Контролируйте `/grim alerts` и Simulation/VehicleTimer. Локальный сервер не изменяет production-конфигурацию 2b2t.org.ru.
